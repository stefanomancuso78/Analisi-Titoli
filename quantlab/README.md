# Quarantined quantitative and development-method laboratory

The published report is a historical allocation-method experiment, not a live recommendation or proof of alpha. It uses 40 usable stocks from the current watchlist and 125 common raw USD closes from retrospective-pilot-v1. FLNC was excluded by a declared discontinuity check, not by its later return. Survivor/selection bias and incomplete corporate-action coverage remain explicit. Every result, including losses, is retained.

Create a separate Python environment and install requirements.txt (Riskfolio-Lib 7.4.1). Run run_portfolio_lab.py with --sources pointing at the original collected retrospective files and --output reports/allocation-lab-v1.json. The source SHA-256 values in the report identify the exact inputs. Run `python -m unittest discover -s quantlab -p 'test_*.py'` with that environment.

Riskfolio-Lib is a third-party BSD-3-Clause library by Dany Cajas: https://github.com/dcajasn/Riskfolio-Lib . No endorsement is implied. HRP and minimum-CVaR are actually executed through the library, then projected to the shared experimental name, sector and exposure caps. The projection is not claimed to preserve global CVaR optimality. Equal-weight and inverse-volatility methods provide controls. Decisions use past closes only and execute at the next close. Trading-value fees are applied, but taxes, dividends, FX and intraday market impact are not modeled. These limitations prevent any claim of production execution realism or financial suitability.

compare_methods.py is separate. It consumes owner-authorized exports of real development-method runs, pairs matching tasks/replicates, computes treatment-minus-minimal deltas and bootstraps by task, not by individual repeated runs. Empty/insufficient samples produce no superiority claim. Never populate it with hypothetical LLM runs or substitute character counts for token observations. There is no configured Claude runtime in this workspace, so a Claude-versus-Codex experiment has not been executed.
